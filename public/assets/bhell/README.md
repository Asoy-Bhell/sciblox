# Bhell expression PNGs

Five sprites generated with the built-in OpenAI image-generation tool, based on
the user's Bhell reference and the existing `public/assets/bhell-guide.png`.
Original source images remain in the Codex generated_images directory; these
copies are bundled with the app for offline use. No runtime image generation.

Prompt set (identity-preserving image edits):

> Use case: identity-preserve. Asset: transparent PNG mobile game NPC sprite.
> Preserve exactly the character's recognizable face, bobbed dark hair, white
> and cobalt cap with cyan hexagon badge, blue vest, white shirt and backpack.
> Same polished 3D cartoon rendering and waist-up scale as reference. Face
> viewer; entire cap and both hands inside frame, generous transparent margins,
> centered. Genuinely transparent background with no glow, no shadows behind
> character, no scenery, text, labels, border or other characters. Make one
> matching expression sprite, not a sheet.

Per-file pose requests:

- `wave.png`: Waving with one open hand, warm welcoming smile.
- `explain.png`: Explaining, one open palm presenting an idea, attentive friendly smile.
- `think.png`: Thinking gently, one finger near her chin, thoughtful eyes, closed smiling mouth.
- `celebrate.png`: Celebrating a learner's success, both hands raised in small happy fists, joyful smile.
- `encourage.png`: Encouraging the learner with a clear thumbs-up and reassuring friendly smile.

The wave edit used the original full-body Bhell image. The other four edits
used the generated wave sprite as their style/identity reference.
